# Bem-vindo ao Aratu

O Aratu é uma maneira de escrever música com o teclado do computador e
ouvir na hora. Você escreve como um músico pensa: em compassos, tempos,
notas e cifras. Aperta **Ouvir**, e a música toca. Muda uma letra, e a
música muda junto.

Este livro ensina o Aratu do começo, uma ideia de cada vez. Você não
precisa saber programar. Ajuda saber um pouco de música, mas também se
aprende música aqui.

## Como este livro funciona

- Cada lição explica uma ideia com **exemplos** que você pode ouvir e
  mudar à vontade. Se bagunçar, aperte **Recomeçar**.
- Embaixo de cada exemplo aparece uma **grade**: os compassos, os tempos
  numerados e cada símbolo no lugar onde soa, como um professor desenharia
  no quadro. Dá para mexer nela: arraste um símbolo para outro lugar, clique
  num espaço vazio para acrescentar e num símbolo para tirar, e o texto muda
  junto.
- Os **exercícios** pedem que você escreva algo. **Ouvir como deve soar**
  toca o objetivo; **Conferir** compara o que você escreveu com o objetivo
  pelo som e diz, compasso por compasso, onde está a diferença.
- Se algo estiver escrito errado, o Aratu explica com palavras de músico,
  em vez de "erro de sintaxe".

Seu progresso fica guardado neste navegador, e a lista de lições ao lado
mostra um ✓ em cada lição terminada.

## O primeiro som

Aperte **Ouvir**:

```aratu
hh = c c c c
```

Isso é um compasso de chimbal com quatro batidas. `hh` é o nome da linha
(de *hi-hat*, o chimbal), e cada `c` é uma batida do chimbal fechado. O
compasso se repete sem parar até você apertar **Parar**. Tudo no Aratu se
repete assim, como um loop.

> Troque um dos `c` por `o` e ouça de novo: `o` é o chimbal aberto. Você
> pode mudar o texto com a música tocando; a mudança entra no começo do
> próximo compasso.

## Mais de uma linha

Cada instrumento da bateria ganha a sua linha. Ouça as três juntas:

```aratu
hh = c c c c
bd = b - b -
sd = - s - s
```

`bd` é o bumbo (*bass drum*) e `sd` é a caixa (*snare drum*). O `-` é um
silêncio: naquele tempo, aquele instrumento não toca. Bumbo no 1 e no 3,
caixa no 2 e no 4: essa é a batida mais comum do rock e do pop.

## Seu primeiro exercício

Escreva uma linha de caixa que toque nos **quatro** tempos. Ouça o objetivo
primeiro, depois troque os silêncios e aperte **Conferir**.

```aratu exercise
sd = - - - -
```

```aratu answer
sd = s s s s
```

Na próxima lição você vai ver o que é um compasso para o Aratu, e como
escolher o andamento.
