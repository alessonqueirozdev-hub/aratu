# The Aratu manual

The manual now lives in the editor, in Portuguese, Spanish and English:
open <https://aratu.live/#/manual> and every
example can be heard and changed on the page.

Its text is kept in the repository, one file per language:

- [book/pt/manual.md](../book/pt/manual.md) (português)
- [book/es/manual.md](../book/es/manual.md) (español)
- [book/en/manual.md](../book/en/manual.md) (English)

The course that teaches the language step by step, with exercises, is in
`book/<lang>/learn/`. Design decisions and open questions are in
[DESIGN-NOTES.md](DESIGN-NOTES.md).
